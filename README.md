# The-Wheel-of-Ne3ma
عجلة النِعم اليومية هي أداة تفاعلية هادئة تساعدك على تحويل الامتنان إلى عادة يومية مبهجة. بلمسة واحدة، تدور العجلة لتختار لك عشوائياً نعمة من بين 100 نعمة شاملة في الدين، الجسد، النفس، والكون، مع اقتراح ذكر مناسب لها؛ لتكتبها في ورقتك وتعلقها أمامك طوال اليوم. رفيقك الصباحي البسيط على كروم لتجديد الشكر والسكينة في حياتك
